One sentence explaining the modern internet to a traveler from 1800, built only from things a person of that year could already picture: a post office, a library, a letter, a book, a table. The program writes exactly that sentence to `/output/entry.txt` and nothing else. The sentence is 155 characters, one sentence, no word coined after 1800 in the picture itself. Deterministic, Python 3.13 standard library only, no network, no secrets.

## Run it

```sh
python3 main.py
```
